# Stage 1C.2.5 GIS review — source and method notes

## Inputs
- Frozen USGS target catalogue v002; SHA-256 `0e20c3ef9268e728d320dcf55e18d66638aa92f66371af2915a34760f9837315`.
- Stage 1C.2.4 provisional candidate crosswalk v001.
- Stage 1C.2 tectonic overlay v001.
- Stage 1C.2.3 boundary-distance audit v001.
- Hasterok et al. (2022) global plates/subplates, geological provinces and plate-boundary linework, source revision `6cdcbf021178e9adf65e7f9c3d77c5497a976bf4`.
- Bird (2003) PB2002 plates and orogens GeoJSON layers.

## Map interpretation
Event colours show the **original Stage 1C.2 pilot assignment**, not a new tectonic classification. Black-ringed points have one or more priority edge-case flags. Gray source polygon outlines are Hasterok plate/subplate polygons; pale dotted outlines are geological provinces; blue dash-dot outlines are PB2002 plate polygons; red dashed outlines are PB2002 orogens; line colours distinguish the Hasterok boundary `type` attribute. Dashed black rectangles are the original exploratory pilot boxes.

## Edge-case rules
The ledger is generated by explicit field-value and assignment rules in the included script. It preserves one row per event-flag, so an event may appear more than once in `edge_case_ledger_v001.csv`. `event_level_gis_review_v001.csv` is the one-row-per-event master table with a semicolon-delimited flag list. These flags are review prompts—not automatic reassignment or exclusions.

## Important limitations
1. One invalid Hasterok Antarctic plate polygon was repaired in memory with `shapely.make_valid` for clipping/rendering only; source file was not modified. The maps use source layers at their supplied present-day geometries and do not reconstruct historical plate boundaries at each earthquake origin time.
2. A nearest mapped-boundary line is not a rupture plane, causative fault, slab surface or hypocentre-to-fault distance.
3. PB2002 plates/orogens, Hasterok plate/subplate polygons, geological provinces and boundary-line types are distinct source concepts and must not be collapsed into one label.
4. The event catalogue is magnitude-thresholded and does not represent all seismicity. Outside-pilot events are not controls or a tectonically inactive set.
5. No new supporting earthquakes were queried, no sequence labels were assigned, and no final study regions were frozen.

## Reproduction
With Python packages `pandas`, `geopandas`, `shapely`, `numpy`, `matplotlib`, run:

```bash
python scripts/build_stage1c2_gis_review_v001.py --input-dir inputs --source-dir inputs/tectonic_sources --output-dir rebuilt_output
```

The script assumes the four analysis input CSVs are in `inputs/`; the shapefile and GeoJSON source layers are in `inputs/tectonic_sources/`.
