## 1. Key Audit Findings Resolved in Batch 08

1. **Isolation of 13 deep Celebes Sea / Moro Gulf slab events (523.2-640.6 km) mis-tagged as `SUNDA_JAVA`:** Hasterok's `Sunda` polygon wraps northeast across Borneo into Moro Gulf, capturing 13 deep slab earthquakes beneath southern Mindanao (including the 2010-07-23 Moro Gulf M7.3/M7.6/M7.5 deep triplet). All 13 are flagged `MOVE_TO_SEPARATE_CANDIDATE` (`CELEBES_MORO_GULF_DEEP_SLAB_REVIEW`).
2. **Unification of the 2012 Wharton Basin M8.6 / M8.2 doublet and 7 other outer-rise/oceanic-lithosphere events:** `official20120411083836720_20` (M8.6, Hasterok `Capricorn`) and `usp000jhjb` (M8.2, Hasterok `Indian`) are grouped with 7 other Wharton Basin / Indo-Australian outer-rise events into `SUNDA_WHARTON_BASIN_OUTER_RISE_REVIEW` so they are not lost in `UNASSIGNED_OUTSIDE` or mixed with megathrust interface ruptures.
3. **Northern Sumatra / Nicobar boundary cleanup:** Separates northern Aceh crustal faulting (`us10007ghm`) and Nicobar junction seismicity (`us10003vry`) from the Java arc segment.
